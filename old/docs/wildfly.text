
* To run Wildfly at localhost port 8080
* Just run the ./standalone.sh
* Admin console will be http://localhost:9990/console

* To run the server at diffrent port

* ./standalone.sh -Djboss.socket.binding.port-offset=1000
* The new port will be  8080 + 1000 = 9080
* Admin console will be http://localhost:10990/console
* i.e 9990 + 1000 = 10990


* Binding public interface to different ip(s), default is 127.0.0.1
* ./standalone.sh -b=192.168.1.1 


*  bind to all available IP addresses, then you can do:
* ./standalone.sh -b=0.0.0.0

* WildFly “management” interface can be bound to a specific IP address as:
* ./standalone.sh -bmanagement=192.168.1.14

* Or, bind “management” interface to all available IP addresses as:
* ./standalone.sh -bmanagement=0.0.0.0

* Of course, you can bind WildFly “public” and “management” interface    together as:
* ./standalone.sh -b=0.0.0.0 -bmanagement=0.0.0.0
